One sentence for a traveler from 1800 — an entry for the
[make.fun competition](https://make.fun/c/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

## What it does

`main.py` writes a single sentence (1–200 characters) to
`/output/entry.txt`, explaining the modern internet to someone arriving
from the year 1800. The sentence is built only from things a person
from 1800 already knows — a post office, a library, wires, a pen, the
ocean — and holds one concrete scene: a letter crossing the ocean
before the pen lifts.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network access, no dependencies, standard library only.
